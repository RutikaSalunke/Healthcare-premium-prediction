# Healthcare-premium-prediction
A Machine Learning web application built with Python and Streamlit to predict health insurance costs based on user information. The project demonstrates data preprocessing, predictive modeling, and an interactive user interface for estimating insurance expenses.
The project demonstrates how machine learning can be applied to insurance cost estimation through data preprocessing, predictive modeling, and an interactive web interface.

🎯 Objectives

Predict estimated health insurance costs using machine learning.

Build an interactive and user-friendly web application.

Apply data science concepts to a real-world problem.

Demonstrate model deployment using Streamlit.

🛠️ Technologies Used

Python – Programming language

Pandas & NumPy – Data manipulation and numerical computing

Scikit-learn – Machine learning

Streamlit – Web application development

Pickle – Model serialization, if used by the project

✨ Features

Interactive user input interface

Health insurance cost estimation

Machine learning-based prediction

Simple and accessible web interface
